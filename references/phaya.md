# Phaya MCP (เสียงพากย์ เพลง ภาพ วิดีโอ AI)

เครื่องมือ: `generate_speech`, `generate_music`, `generate_image`, `generate_video`, `jobs_wait`, `job_status`,
`list_models`, `get_balance`, `upload_media`, `cancel_job` ทุกงานเป็นแบบ async: generate → ได้ job_id → `jobs_wait`

**ใช้ credit จริงทุกครั้ง** ก่อน gen ให้บอกจำนวนโดยประมาณและได้คำยืนยันจากผู้ใช้ (ยกเว้นผู้ใช้อนุมัติงบไว้แล้วในรอบนั้น)
เรียก `get_balance` ก่อนและหลังเสมอ แล้วรายงานยอดที่ใช้

## เสียงพากย์ไทย

- `language: "th"` เสียงที่ผู้ใช้เลือกแล้ว: **Leda** (สดใส เป็นกันเอง)
- สะกดตามเสียงเพื่อให้อ่านถูก: "เอไอ" แทน AI, ชื่อแบรนด์ภาษาอังกฤษเขียนเป็นไทย (เช่น "สตีมคิด")
- gen **ทีละประโยค** เพื่อวางเวลาเองได้ ประโยคละ 2–5 วินาที
- ไฟล์ที่ได้มีช่วงเงียบหัวท้าย → `scripts/vo.sh` ตัดออกแล้วตรวจว่ามีเสียงจริง
- **เก็บไฟล์ดิบไว้ใน `vo-raw/` ทันที** ลิงก์หมดอายุใน 7 วัน

## ทาง AI gen ล้วน (ไม่ทำ 3D)

เหมาะกับฉากคน บรรยากาศ ที่ไม่มีตัวหนังสือในภาพ (AI ทำตัวหนังสือไทยและหน้าจอแอปเพี้ยน)

1. ภาพตั้งต้นช็อตแรกด้วย nano-banana-2 → ช็อตถัดไปส่งภาพแรกเป็น `image_urls` บอกให้ใช้คนเดิม/โทนเดิม
2. prompt ใส่ "No text, no letters, no logos" ทุกครั้ง
3. image-to-video ด้วย seedance-1.5-pro ความยาวให้พอดีเสียงพากย์ของช็อตนั้น (4/8/12 วิ)
4. รวมด้วย ffmpeg: `xfade` ระหว่างช็อต, `adelay` วางเสียงพากย์, เพลง `volume=0.22`, ซับและการ์ดท้ายด้วยไฟล์ ASS (`ass=` filter, ฟอนต์ Sarabun) เพราะ libass จัดสระไทยถูก
5. `scripts/finalize.sh` แล้วส่ง

ตัวอย่างคำสั่ง ffmpeg ที่ใช้ได้ผล: ต่อ 3 ช็อต (4+8+4 วิ) + การ์ดสี 3 วิ, xfade 0.4 วิ ที่ offset 3.64 / 11.28 / 14.92
